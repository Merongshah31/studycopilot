# Backend Python Agents (Step 1)

This folder is the Python agent layer for StudyPilot.

Current phase keeps only the **Router Agent** so we can build incrementally.

## Included now

- `router_agent.py`: intent detection + plan drafting
- `state.py`: shared run-state contracts

## Not included yet

- task/calendar/ui execution agents
- supervisor orchestration graph

Those will be added in the next steps.
